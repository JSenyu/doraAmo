# DoraAmo

[中文](README.md) | [English](README_EN.md)

*Minecraft 1.12.2 · Forge*

你在末地城找到龙首，终于摸到那扇门的门槛。用黑曜石、钻石和龙首拼出一扇两格高的任意门，推开它——门后暂时是空白。空手敲门，它会记住「坐标换算」：主世界与下界按八比一互通，像真正的传送门那样。

想去更远的地方，先做出协调器。对主门使用它，选定维度、坐标，或是一片群系、一座结构；探索确认落点后保存。你再度走入门中，静立数秒，另一端会立起一扇子门。从子门回来，仍落在主门一侧。改主意时覆盖目的地，旧的子门会消失，新的在别处重生。

空手拿着协调器挥一下，它会告诉你最近那扇门在哪边、有多远。
