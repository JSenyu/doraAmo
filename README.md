# DoraAmo

[中文](README.md) | [English](README_EN.md)

适用于 Minecraft 1.21.1（NeoForge，ModDevGradle）的传送门模组。

添加了在末地城之后的玩法，提高后期移动的便捷性，可以通过任意门传送到指定的任意地点。

任意门是一扇两格高的门。走进门中稍作停留，即可前往另一端。默认情况下门后是空白的；也可以切换为坐标换算，在主世界与下界之间按比例互通。想去更远的地方时，用协调器为门设定目的地，可指定维度与坐标，或前往某一生物群系、某一结构。主门与子门成对存在，方便来回往返。

制作任意门需要龙首。做出任意门之后，再做出协调器，就能真正决定门通向哪里。
