# DoraAmo

[中文](README.md) | [English](README_EN.md)

A portal mod for Minecraft 1.12.2 (Forge).

Place a two-block-tall Anywhere Door in the world. Step inside and wait a moment to travel to the other side. Use the Coordinator to set where it leads—another dimension, a set of coordinates, a biome, or a structure. Main doors and sub-doors come in pairs for easy return trips.

Crafting the door requires a dragon head. Craft the Coordinator afterward to decide where the door truly goes.
